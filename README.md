# Sippin Website Build

Build a single-page, premium website for "SIPPIN" - an eco-friendly water bottle.

THEME: Minimal, nature-inspired, premium. Colors: Sage Green #A8C3B0, Off-White #F5F1E8, Black #111111. Font: Modern sans-serif, big headings. Rounded corners, soft shadows, smooth scroll animations.

SINGLE PAGE SECTIONS (in order):

1. NAVBAR: Logo "SIPPIN" left, Menu: Features, Shop, Impact, right button: "Buy Now - $34"

2. HERO: Left - Headline "Sip Sustainably." Sub-headline "The last bottle you'll ever need. 100% BPA-free, keeps cold 24hrs, hot 12hrs." 2 buttons [Shop Collection] [Watch Story]. Right - Large floating image of the Sippin bottle with soft shadow.

3. FEATURES STRIP (3 cards in a row):

- BPA Free & Non-Toxic

- Double-Wall Insulated

- Made from Recycled Steel

4. PRODUCT SHOWCASE: Title "Find Your Sippin". 3 bottles in a row: Sand Beige, Forest, Midnight with price $34 and Add to Cart hover effect.

5. IMPACT BANNER: Full-width green background. Text "1 Sippin = 167 Plastic Bottles Saved Per Year" with small icons of earth, recycle, water drop.

6. ABOUT: 2 columns - left image of person hiking with bottle, right text "Designed for Life, Made for the Planet. We started Sippin to end single-use plastic."

7. TESTIMONIALS: 3 small customer reviews with 5 stars.

8. FINAL CTA: "Ready to make the switch?" Email input + "Get 10% Off" button.

9. FOOTER: Minimal footer with Instagram, TikTok, FAQ, Contact.

Make it fully responsive, Apple/Sturdy like Stanley website, sticky buy button on mobile. Use my uploaded Sippin bottle images.
